# 2026-11-03

## npm run build 失败：esbuild 0.28.2 与 vite 6.4.5 冲突

- 现象：`npm run build`（vite build --mode production）在 `?worker&inline` 转换阶段失败：
  `Transforming destructuring to the configured target environment ("chrome87","edge88","es2020","firefox78","safari14" + 2 overrides) is not supported yet`。
  1453 modules 后中断。`bun run build` 同样失败 → 不是 npm/bun 的问题。
- 根因：package.json 的 `overrides.esbuild = ^0.28.2`（commit 099da50 为消 audit 告警而钉），
  而 vite 6.4.5 官方依赖 esbuild `^0.25.0`。esbuild 0.28.2 的特性表把 **safari14** 标为不支持解构且无法降级；
  vite 默认 `modules` target 正好含 safari14，于是所有解构转换直接报错。
- 逐项实测（esbuild 0.28.2）：es2020/chrome87/edge88/firefox78/safari16 OK；**safari14 与 ios14 FAIL**，
  safari14.1 / ios15 起 OK。esbuild 0.25.12 对同样的 modules target 全部 OK。
- 修复：vite.config.ts 的 `build.target` 改为 `["es2020","edge88","firefox78","chrome87","safari14.1"]`（仅抬高 safari 一项）。
  验证：npm run build EXIT=0，3867 modules，25s，产出 build/prod/{main.js 6.8MB, manifest.json, styles.css 164KB}。
- 备选修复：把 overrides 的 esbuild 降到 ^0.25.12 后重装（未实测 npm audit 是否复现告警）。
